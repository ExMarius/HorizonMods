# Simulare interactivă CL1000

Pornește `node server.cjs` din acest director (port implicit 4188). Este nevoie de dependența `three` instalată cu `npm ci` în `next-vehicle/vizualizator-glb`; acest director furnizează și cititorul Blockbench comun. Serverul citește direct fișierul utilizatorului `downloads/glb-imports/cb7869cfffcd6e70/model.bbmodel`, fără să îl scrie. Fără acest fișier local, aplicația afișează o eroare în loc să încarce alt model.

Previzualizarea scalează ansamblul la lățime 4,8 blocuri și construiește pivoți numai în memoria browserului. Folosește numele grupurilor originale pentru roți, rabator și tub; bucăți ale hederului sunt selectate euristic după poziție și pot include/exclude piese incorect. Pivoții sunt estimativi, iar textura poate avea diferențe de randare față de Blockbench.

Comenzile simulează înainte/înapoi, viteză, rotirea roților, ridicare heder, oprire graduală a rabatorului la −6°, colectare a plantelor mature în mișcare, particule, un buncăr de 300 unități, un tub până la 90° spre exteriorul stâng (rotație geometrică negativă pe Y) și transfer limitat în remorca agricolă poziționată la gura tubului. Acestea sunt **exclusiv simulări de browser**, nu implementează comportament în Paper, nu modifică lumea, inventarele sau economia serverului și nu validează performanța în Minecraft. Capacitățile din preview nu sunt valori aprobate pentru joc. Preview-ul permite alegerea între `tractor_trailer_body` (o axă) și `tractor_trailer_modern_body`, `tractor_trailer_modern_axle`, `tractor_trailer_modern_drawbar` (remorca mare cu două axe), alături de `utb_650_body` și `utb_650_wheel_*`. Volumul de recepție este estimat din dimensiunile benei fiecărui model, nu dintr-un rig validat în Minecraft. Numele RM-2 nu este identificat separat în codul serverului, așa că asocierea exactă trebuie confirmată. Modelul nu este modificat și niciun fișier de pe serverul de joc nu este instalat.

Preview-ul actual simulează separat grâul și semințele (o unitate din fiecare per plantă, doar pentru demonstrație), cu UTB-ul și remorca agricolă din modelele proiectului care pot urmări combina și imagini decorative de grâu și semințe căzând din tub în timp ce transferul este activ. Verificarea demonstrativă folosește interiorul benei și înălțimea gurii tubului; nu este încă legată la remorca sau inventarul de pe server.

Texturile pentru grâu, semințe și stadiile 3/7 ale culturii sunt copii locale din asset-urile Minecraft 1.21.4, folosite numai de preview, în `downloads/minecraft-preview-textures/`. Nu sunt incluse în Git; dacă lipsesc, se pot descărca din nou prin GitHub API din `InventivetalentDev/minecraft-assets` ref `1.21.4`, sub `assets/minecraft/textures/item/` și `assets/minecraft/textures/block/`. Simularea folosește randare 2D a itemelor, nu iteme/entity Minecraft reale.

În preview, alegerea altei remorci oprește transferul și păstrează separat conținutul fiecăreia. Capacitatea de 300 este doar demonstrativă, nu capacitatea inventarului de pe server.

## Exemple decorative de paie
Panoul „Exemple în spatele combinei” afișează o brazdă propusă din fire 3D sau un cub cu texturile Minecraft 1.21.4 `hay_block_side` / `hay_block_top`, ori ambele. Sunt mostre statice atașate de combină, nu urme persistente și nici producție sau presă de balotat. Brazda este doar o propunere, nu un bloc vanilla; HAY_BLOCK este balot de fân în Minecraft, folosit aici doar ca exemplu vizual. Descărcați texturile de balot în `downloads/minecraft-preview-textures/` din `InventivetalentDev/minecraft-assets`, ref `1.21.4`, `assets/minecraft/textures/block/`, dacă lipsesc.
