# Preview 3D: pompă roșie nouă

`npm install && npm start` pornește preview-ul pe portul 4185, accesibil pe `0.0.0.0`. Pompa și furtunul sunt concepute de la zero în `app.js`. Pistolul folosește geometria modelului vechi MrCrayfish (`vehicle-plugin/src/main/resources/assets/vehicle/models/vehicle/nozzle.json`), cu nuanțele portocalii ale texturii transformate în roșu și piesele întunecate păstrate. Copia de preview se află în `assets/`; creditul original rămâne în JSON. Priza folosește centrul mânerului modelului, iar racordurile cu manșon și inele sunt geometrie suplimentară de preview. Corpul are aproximativ 0,94 × 1,84 × 0,72 blocuri, afișaj, butoane, locaș lateral și pistolul vechi cu corp roșu și detalii întunecate. Textul este desenat în browser, nu este încă un asset Minecraft.

Furtunul are 16 segmente; capătul de la pompă este fix, iar celălalt se calculează din transformarea conectorului pistolului. O curbă cu lăsare calculată aproximează greutatea furtunului. Aceasta este o demonstrație, nu un model fizic sau o implementare Paper. Jucătorul, mâna și perspectiva sunt schematice. Aspectul, punctele exacte de prindere, distanța și funcționarea trebuie confirmate de utilizator și apoi validate în Minecraft.

Nu modifică serverul. Pompa veche există deja în plugin, iar codul ei este marcat ca validat și înghețat; acest concept este separat. Nu se înlocuiesc pompele existente, datele sau resource pack-ul înainte de confirmarea designului și stabilirea compatibilității.
